# OS_lab5

Лабораторная работа №5 «Динамические библиотеки», вариант 16.

```sh
cmake -S . -B build
cmake --build build
cd build
printf '1 1 20\n2 48 18\n' | ./linked
printf '1 1 20\n0\n1 1 20\n2 48 18\n' | ./dynamic
```

C11, CMake 3.16 или новее, Linux либо macOS. Для интерактивного
запуска введи `./linked` или `./dynamic`. Команда `1 A B` считает
простые числа от A до B, `2 A B` вычисляет НОД. Команда `0` в
`dynamic` переключает библиотеку. Выход по Ctrl+D.

Команды проверки и трассировки — в «Запуск.txt». Разбор кода — в
«Объяснение_ЛР5.md».
